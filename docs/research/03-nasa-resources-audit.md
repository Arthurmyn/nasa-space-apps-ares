# Ресурсы NASA из челленджа — проверка

Дата проверки: 14 ноября 2026.
Источник списка: раздел «NASA Data & Resources» страницы челленджа (5 ссылок).
Цель: понять, что из каждого ресурса реально пригодится MARSWALK, и закрыть часть Q2 («что перечислено во вкладке Resources 2026»).

Метод: страницы загружались напрямую по HTTP, без браузерного рендеринга. Для сайтов, которые строятся скриптами в браузере, видна только «оболочка» — это отмечено отдельно.

Пометки: **[факт]** — получено из ответа сервера; **[вывод]** — интерпретация; **[не проверено]** — не удалось увидеть.

## 1. JPL Mars Trek

URL: https://trek.nasa.gov/mars/

### 1.1. Что это

Веб-портал JPL для исследования Марса: карта с наложением слоёв орбитальных данных, профили, 3-D. **[факт]** Статический HTML — только заголовок «Mars Trek» и логотип; интерфейс собирается скриптами в браузере.

### 1.2. API каталога

**[факт]** Есть JSON-эндпоинт поиска (формат похож на Solr):

```
https://trek.nasa.gov/mars/TrekServices/ws/index/eq/searchItems
    ?proj=urn:ogc:def:crs:EPSG::104905
    &start=0
    &rows=30
    &key=<текст запроса>
```

Параметр `key` — свободный текст; внутри превращается в запрос вида `text:(Gale* AND DEM*)`.

### 1.3. Что нашлось по Гейлу

Запрос `key=Gale` вернул **4** записи **[факт]**:

| Название | productLabel | Тип | Инструмент | Рамка (lon, lat) | Примечания |
|---|---|---|---|---|---|
| Curiosity Landing Site | `Curiosity Landing Site_bookmark` | закладка | — | 136.7834…138.0688°E, −5.1084…−4.0661° | Просто закладка вида карты |
| MRO CTX, Gale Crater Mosaic | `Gale_CTX_BlockAdj_dd` | продукт | CTX | 135.1843…139.2413°E, −6.5733…−2.8078° | В описании «до 6 м/пиксель». Весь кратер |
| **MRO HiRISE, Gale Crater DEM** | **`Gale_DEM_SMG_1m`** | продукт | HiRISE | **137.1224711…137.7298129°E, −4.9254743…−4.2489631°** | Подробности ниже |
| Gale | `Gale` | номенклатура | — | точка 137.811°E, −5.3672° | Центр кратера по номенклатуре |

Подробности `Gale_DEM_SMG_1m` **[факт]**:
- `item_DBID`: 294172
- `item_UUID`: a0f5221a-0a08-40b9-ae82-75a49aac5afe
- категории: Topography / DEM
- миссия: Mars Reconnaissance Orbiter; инструмент: HiRISE
- размер файла: 5 775 684 529 байт (~5.8 ГБ)
- создан: 2020-06-25T22:50:52Z
- `serviceTypes`: Mosaic, raster
- превью: `https://trek.nasa.gov/tiles/Mars/EQ/Gale_DEM_SMG_1m/thumbnail/Gale_DEM_SMG_1m-`
- числовое поле Resolution = 0; «1m» есть только в имени продукта
- поле coverage = «Global» — противоречит рамке, видимо, ошибка метаданных

Запрос `key=HiRISE DTM Gale` вернул **0** записей **[факт]** — отдельных HiRISE DTM (вида `DTEEC_...`) в каталоге Trek по Гейлу нет. В частности, нет нашего `DTEEC_001488_1750_001752_1750_U02`.

### 1.4. Словарь каталога

**[факт]** В фасетах каталога есть категории: Slope, Slope Colorized, Hillshade, Traverse Path, Mosaic, Color Mosaic, Photometrically Corrected, Crater.
Миссии в фасетах: Mars 2020, MRO, MGS, Mars Odyssey, MEX, Viking, Mixed. **MSL / Curiosity в списке миссий нет.**

**[не проверено]** Есть ли по Гейлу готовые слои Slope / Hillshade и HiRISE-ортоснимки — отдельными запросами не искали.

### 1.5. Тайлы и скачивание

**[вывод]** По пути превью тайлы, вероятно, лежат по шаблону `https://trek.nasa.gov/tiles/Mars/EQ/<productLabel>/...` (WMTS или XYZ). **[не проверено]** Формат и наличие прямой ссылки на полный файл DEM: в JSON каталога ссылки на скачивание нет.

### 1.6. Что это значит для нас

- **R0:** `Gale_DEM_SMG_1m` — главный запасной кандидат, если основной DTM не покрывает участок ровера. **[вывод]** Это, скорее всего, тот самый «MSL 1 m DEM mosaic» из таблицы слоёв контекста; если так, в местах дозаполнения CTX/HRSC в UI обязательно «1 m grid ≠ 1 m data».
- **Q7 (раздача тайлов):** если тайлы Trek доступны по стандартному шаблону, ортоснимок / hillshade можно показывать прямо с серверов Trek, не раздавая свои.
- **Q11 (делает ли Trek маршруты):** в каталоге есть категория «Traverse Path» — это готовые слои пройденных путей, а не планировщик. В самом интерфейсе Trek есть инструменты профиля высот; планировщика EVA с бюджетом времени и точкой невозврата там нет **[вывод, по знанию продукта; в этой проверке интерфейс не открывался]**.
- Координаты в каталоге — в `EPSG::104905` (ESRI Mars 2000). **[не проверено]** сфера или эллипсоид; сверить перед наложением (см. `02-r0-coverage-gate.md`, шаг 4).

## 2. USGS-NASA Planetary Geologic Mapping Program

URL: https://astrogeology-usgs.hub.arcgis.com/pages/interactive-maps-mars

**[факт]** Страница вернула HTTP 200, но текст — только заголовок «Interactive Maps: Mars» (22 символа). Список карт, масштабы и ссылки подгружаются скриптами ArcGIS Hub и при прямой загрузке не видны.

**[вывод, по общему знанию программы]** Программа публикует стандартизованные геологические карты: глобальную карту Марса (масштаб 1:20 000 000) и региональные/квадрантные карты. Для участка в несколько километров это слишком крупный масштаб.

Пригодность:
- как **контекстный слой** «геологическая единица» на обзорной карте — да, если найдётся карта, покрывающая Aeolis Mons;
- для маршрута — нет.

**[не проверено]** Есть ли среди карт что-то именно по Гейлу / горе Шарп. Для проверки нужно открыть страницу в браузере или запросить ArcGIS Hub API напрямую.

## 3. Curiosity's Proposed Path up Mount Sharp

URL: https://science.nasa.gov/resource/curiositys-proposed-path-up-mount-sharp/

**[факт]**
- Название: «Curiosity's Proposed Path up Mount Sharp».
- Номер: **PIA23179** (виден только в именах файлов).
- Опубликовано: 15 мая 2019. Страница обновлена 14 ноября 2024. Файл для скачивания датирован 9 марта 2024.
- Что показывает: анимация предлагаемого маршрута Curiosity вверх по нижней части горы Шарп. Аннотированная версия подписывает районы, которые научная команда хотела исследовать в следующие годы. Упоминается обзорное видео, но ссылки на него на странице нет.
- Данные: несколько инструментов MRO — HiRISE, CRISM, CTX, а также HRSC на Mars Express. Какой из них подложка — не указано.
- Подпись: NASA/JPL-Caltech/ESA/University of Arizona/JHUAPL/MSSS/USGS Astrogeology Science Center.
- Файлы:
  - https://assets.science.nasa.gov/content/dam/science/psd/mars/resources/detail_files/2/22472_PIA23179-combo-rev_main.gif
  - https://assets.science.nasa.gov/content/dam/science/psd/mars/downloadable_items/4/42763_PIA23179-combo-rev_main.gif (GIF 1041 × 586, 2.86 МБ)

**[не проверено]** Какие именно районы подписаны на карте (боксворк, сульфатная толща и т. д.) — текст страницы их не называет, картинка не просматривалась.

Пригодность:
- **Визуальный референс** для того, как NASA сама показывает маршрут на горе Шарп — полезно для дизайна карты и слайда.
- **Слайд контекста** «куда идёт Curiosity» — с подписью автора как выше.
- **Не данные**: маршрут 2019 года, «предлагаемый», устарел примерно на 7 лет. В расчётах не использовать.

## 5. Mars Perseverance Raw Images

URL: https://mars.nasa.gov/mars2020/multimedia/raw-images/

### 5.1. Сам ресурс

**[факт]** Галерея сырых снимков ровера Perseverance (кратер Езеро). HTML — оболочка с «Raw Image of the Week» и кнопкой «View More Images»; сетка снимков подгружается скриптом. Пример снимка дня: sol 1934, камера SHERLOC (`shrlc`).

Пригодность: **нет** — Езеро не наша зона.

### 5.2. Аналог для Curiosity — важная находка

**[факт]** Страница галереи Curiosity (`https://mars.nasa.gov/msl/multimedia/raw-images/`) — почти пустая оболочка. Но за ней работает **открытое JSON API**:

```
https://mars.nasa.gov/api/v1/raw_image_items/
    ?order=sol%20desc
    &per_page=5
    &page=0
    &condition_1=msl:mission
```

**[факт]** Ответ:
- верхний уровень: `items`, `more`, `total`, `page`, `per_page`;
- `total` = 1 519 190 снимков;
- самый свежий sol: **5073** (`date_taken` 2026-11-13T15:17:38Z) — ровер снимает прямо сейчас;
- поля элемента: `id`, `camera_vector`, `site`, `imageid`, `subframe_rect`, `sol`, `scale_factor`, `camera_model_component_list`, `instrument`, `url`, `spacecraft_clock`, `attitude`, `camera_position`, `camera_model_type`, `drive`, `xyz`, `created_at`, `updated_at`, `mission`, `extended` (`lmst`, `bucket`, `mast_az`, `mast_el`, `url_list`, `contributor`, `filter_name`, `sample_type`), `date_taken`, `date_received`, `instrument_sort`, `sample_type_sort`, `is_thumbnail`, `title`, `description`, `link`, `image_credit`, `https_url`;
- камера указана в `instrument` (например, `MAHLI`), ID снимка — в `imageid` (например, `5073MH0001530001900058S00_DXXX`), подпись — в `image_credit` (например, `NASA/JPL-Caltech/MSSS`).

### 5.3. Что это значит для нас

- **R6** требует для каждой цели «Mastcam/Navcam image with ID + credit». API отдаёт ровно это: `imageid`, `instrument`, `sol`, `image_credit`, `https_url`.
- **[вывод]** Через `site` и `drive` снимки можно связать с позицией ровера (те же поля есть в MMGIS-путевых точках: `site`, `drive`). Это даёт «вид от первого лица» рядом с каждой целью.
- **[не проверено]** Параметры фильтрации по камере и диапазону sol (например, `condition_2=...`). Нужно подобрать.
- Ограничение: это **сырые** снимки (raw). Для слайдов и UI лучше дополнительно иметь обработанные PIA-снимки, где они есть (например, PIA26696 из контекста для боксворка).
- Подпись автора показывать дословно из `image_credit`.

## 7. Выводы для команды

1. Из пяти ресурсов челленджа для нас по-настоящему полезен **один** — Mars Trek. Ещё один (Perseverance) полезен косвенно — через аналогичное API для Curiosity.
2. Worldview — Земля, для Марса не нужен. Геологические карты USGS — максимум контекстный слой.
3. Для R0 появился **запасной DEM** (`Gale_DEM_SMG_1m`), и последняя точка ровера в его рамке. R0 этим не закрыт — нужен реальный контур и все точки с sol 4534 (см. `02-r0-coverage-gate.md`).
4. Для R6 есть готовое API снимков Curiosity с подписями — Alikhan может подбирать снимки к целям уже сейчас.
5. Для Q11 (новизна против Trek) — в Trek есть слои пройденных путей и профили, но нет планировщика EVA с бюджетом времени, точкой невозврата и происхождением чисел. Для слайда новизны это надо подтвердить, открыв интерфейс Trek в браузере.
