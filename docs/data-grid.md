# Генерация сетки Gale boxwork

Формат файлов: [DATA_CONTRACT.md](DATA_CONTRACT.md). Запуск из корня репозитория:

```powershell
python -m pip install -r scripts/requirements-grid.txt
python scripts/make_fake_grid.py --output-root "$env:TEMP/ares-fake-grid"
python -m pytest scripts/tests -q
```

Тестовый генератор создаёт наклонную плоскость, два холма и овраг, плавно
мелеющий к северу. Западный и восточный края соединены по ячейкам с уклоном
не выше 15° (8 соседей). В метаданных
`is_test_data: true`, источник явно обозначен как синтетический. Закоммиченные
файлы в `backend/data/gale-bx/` и `frontend/public/data/gale-bx/` — настоящая
сетка HiRISE DTM `DTEEC_009149_1750_009294_1750_U01`, `is_test_data: false`.
Тесты генерируют синтетическую сетку только в `tmp_path`.
Итоговая настоящая сетка: 316 × 430, ячейка 2 м; 765 118 байт для сетки,
767 745 байт вместе с `stops.json` и `assumptions.json` (JSON с LF в Git).
Проверка: `python -m pytest scripts/tests -q` — 51 тест пройден.

Генерация по настоящему DTM (заменяет эти файлы):

```powershell
python scripts/make_slope_grid.py data/r0/raw/DTEEC_009149_1750_009294_1750_U01.IMG
```

DTM уже найден локально в указанном месте. Если его нет в другом checkout,
скачивание оригинала по URL из `scripts/r0_inputs.json`:

```powershell
New-Item -ItemType Directory -Force data/r0/raw | Out-Null
curl.exe --fail --location --retry 3 --output data/r0/raw/DTEEC_009149_1750_009294_1750_U01.IMG https://www.uahirise.org/PDS/DTM/PSP/ORB_009100_009199/PSP_009149_1750_PSP_009294_1750/DTEEC_009149_1750_009294_1750_U01.IMG
```

Оба генератора принимают `--cell` (по умолчанию 1 м), `--handoff` (по умолчанию
`docs/research/r0/gale_bx_handoff.json`) и `--output-root` (по умолчанию корень
репозитория). Последний параметр позволяет проверять синтетические или реальные
данные отдельно, не заменяя закоммиченные файлы. Поддерживаются GeoTIFF и PDS IMG
с указанной CRS.

Сетка охватывает AOI с округлением наружу до целых ячеек. `bbox` соответствует
внешним границам готовой сетки, поэтому может быть чуть шире AOI. Координаты
из формул контракта — координаты краёв ячеек; для индекса используется `floor`.
Центр ячейки расположен в `(col + 0.5, row + 0.5)`. Восточная и южная границы
исключены при индексации. Ячейки с центром вне полигона AOI получают NoData.
Проекция использует сферу Марса радиусом 3396190 м, без EPSG:4326.

Высоты перепроецируются билинейно. Для уклона применяется усреднение по
ближайшему нечётному окну около 5 м (5×5 ячеек при 1 м, 3×3 при 2 м), затем
градиент и `atan(hypot(dx, dy))`. Квантование: `round(deg / 0.5)` с округлением
половин к ближайшему чётному. Окно и соседи градиента должны содержать только
валидные высоты: пропуски не заполняются. По внешнему краю используется
продолжение ближайшей высоты. Уклон там менее точен, чем внутри сетки.
NoData: NaN для высот, 255 для уклонов; PNG прозрачны при отсутствии уклона.
Hillshade освещён с северо-запада: азимут 315°, высота 45°. Один сглаженный
градиент используется и для уклона, и для hillshade.
Цвета PNG: зелёный до `slope_caution_deg`, жёлтый до `slope_limit_deg`, красный
выше лимита. Пороги читаются из `backend/data/gale-bx/assumptions.json`
в папке результата; при отсутствии файла используются 10° и 15°.

`stops.json` содержит шесть точек Curiosity из
`docs/research/r0/rover_sols4534-4805.geojson` (солы 4534, 4554, 4585, 4609,
4655 и 4805) в группе `boxwork`. Это точки из снимка маршрута ровера,
а не подтверждённые научные цели. `source_id: src-msl-traverse` ссылается на
запись в `meta.sources` с URL исходных MSL waypoints и путём снимка.
Все точки внутри bbox, на ячейках не круче 15° и в одной связной области
по 8 соседям. Это проверяет pytest по закоммиченному `slope.bin`.
`assumptions.json` задаёт лимиты 10°/15° и скорость 2 км/ч; источники этих
допущений остаются `TO VERIFY` до проверки документов.

Общий лимит — 3 000 000 байт для обеих папок, включая имеющиеся дополнительные
файлы, например `stops.json` и `assumptions.json`. Под них зарезервировано
`RESERVE_BYTES = 100_000` байт: сама сетка (две копии meta.json, бинарные
массивы и два PNG) должна занимать не более 2 900 000 байт. При превышении
любого из лимитов генератор сообщает об этом и повторяет расчёт с `--cell 2`.
Если лимит всё ещё превышен,
он завершается с ошибкой до записи результатов. Дополнительные файлы он
не создаёт и не изменяет.

AOI в handoff предварительный. Генерация сетки не подтверждает пригодность
участка для планирования; `preliminary` остаётся `true`.
